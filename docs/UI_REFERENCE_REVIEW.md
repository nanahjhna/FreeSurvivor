# 화면별 UI 레퍼런스 검토

## 목적

이 문서는 현재 실행 화면을 기준으로 화면별 시각 방향을 합의하기 위한 검토 문서입니다. 이 단계의 범위는 색상, 프레임, 정보 우선순위, 여백, 버튼 배치, 타이포그래피와 같은 디자인 변경이며, 전투 로직·저장 데이터·입력·씬 흐름은 변경하지 않습니다.

## 세로 화면 기준 재확인

- 디자인 기준은 1080×1920 세로 화면입니다.
- 이전 검토에서 섞였던 가로형 레퍼런스는 최종 레이아웃 기준에서 제외합니다.
- 최종 비교는 사용자가 제공한 세로형 레퍼런스와 현재 게임의 450×800 세로 실행 화면을 기준으로 합니다.
- 화면을 가로로 늘려 배치하지 않고, 콘텐츠 우선순위에 따라 위에서 아래로 쌓는 구조를 사용합니다.

### 캐릭터 선택 모델 표시 규칙

- 캐릭터 선택은 정지 일러스트나 PNG 카드가 아니라 현재 `CharacterData`의 3D 모델을 `SubViewport`로 표시합니다.
- 모델은 대기 애니메이션을 계속 재생하고, 사용자가 드래그하면 회전할 수 있어야 합니다.
- 캐릭터를 선택하면 같은 모델의 장착 무기와 실제 데이터 기반 정보가 함께 갱신됩니다.
- 생성 화면도 직업 목록을 바꿀 때 동일한 3D 프리뷰를 사용합니다.
- 모델 프리뷰 영역은 세로 화면 높이의 약 30~38%를 확보하고, 정보·목록·버튼이 프리뷰를 축소하지 않도록 합니다.

## 공통 디자인 토큰

- 배경: 실제 월드 또는 기존 대표 이미지를 유지하고, 모달 뒤에만 반투명 딤을 사용합니다.
- 프레임: 생존자 거점의 바랜 나무판과 종이를 사용합니다. 풀·덩굴·잎사귀는 UI 장식에 넣지 않습니다.
- 강조색: 주요 버튼은 벽돌색, 선택 표시는 따뜻한 황토색, 위험 표시는 적색을 사용합니다.
- 여백: 세로 화면에서 고정 최소 높이를 줄이고, 실제 콘텐츠가 차지하는 높이에 맞춰 패널을 정렬합니다.
- 스크롤: 내 스킬·가방처럼 데이터가 늘어나는 영역에만 제한적으로 사용합니다. 화면 전체 스크롤은 사용하지 않습니다.
- 데이터: 레퍼런스 이미지의 캐릭터·아이템을 복제하지 않고 현재 프로젝트의 실제 모델·아이콘·텍스트만 사용합니다.

## 화면 일관성 적용 규칙

- 모든 화면은 `UiStyle`의 공통 색상·프레임·버튼·타이틀·안전 영역 함수를 우선 사용합니다.
- 모든 화면은 짙은 목재색·바랜 종이색·벽돌색을 공유합니다.
- 화면군은 `프로필`(캐릭터 선택·정보·장비·가방), `전투`(던전·전투 HUD·레벨업·일시정지·결과), `공통 팝업`(아이템·설정)으로 나누되 같은 토큰을 공유합니다.
- 제목, 닫기 버튼, 선택선과 등급 테두리는 공통 스타일을 따릅니다.
- 세로 화면에서는 상단 제목 → 핵심 콘텐츠 → 상세 정보 → 하단 CTA 순서를 유지합니다.
- 제목판과 버튼은 공통화하고, 배치와 정보 위계는 화면 목적에 맞춥니다.

### 단일 아포칼립스 테마 토큰

- 제목판과 바탕: 바랜 목재와 짙은 갈색
- 정보 카드: 종이색 바탕과 짙은 갈색 글자
- 주요 버튼: 벽돌색 바탕과 아이보리 글자
- 선택 및 위험 표시는 황토색과 적색으로 구분

## 공통 프레임 적용

- 공통 프레임은 화면 크기에 따라 늘어나는 `StyleBoxFlat`으로 구성합니다. 제목판의 간결한 나뭇결과 결과 기록지의 괘선을 Godot에서 그립니다.
- 세로 배치는 타이틀 하단, 캐릭터 3D 프리뷰와 하단 입장, 장비 격자, 던전 안내문, 스킬 카드와 슬롯, 결과 기록지 순으로 각 씬에 적용했습니다.

## 구현 순서

1. 공통 프레임·버튼·탭·등급 테두리 스타일을 정리합니다.
2. 타이틀·캐릭터 선택·캐릭터 정보·장비/가방을 같은 프로필 계열로 맞춥니다.
3. 던전 선택·전투 HUD·레벨업·일시정지·결과를 전투 계열로 맞춥니다.
4. 각 단계에서 기능·데이터·입력 변경 없이 씬/컨트롤 스타일만 수정합니다.
5. 실제 실행 확인 전에는 `구현`으로 승격하지 않고 디자인 초안으로 기록합니다.

## 보류

- 세로 비율별 렌더링 및 기기 확인은 미진행입니다.
- 레퍼런스의 캐릭터, 로고, 아이콘, 배경 이미지를 프로젝트에 복제하지 않습니다.

## 2026-11-26 모바일 UI 개선에 채택한 레퍼런스

FreeSurvivor의 자체 승인 시안은 2026-11-27부터 게임 화면에 직접 적용합니다. 첨부 5장의 15개 화면과 실제 모델·데이터의 연결 규격은 `UI_UX_SPEC.md`에 기록합니다.

- [Nonstop Knight 2](https://play.google.com/store/apps/details?id=com.flaregames.nonstop.action.rpg)의 캐릭터 주변 장착 슬롯 구성을 참고했습니다. 장비 화면의 캐릭터와 슬롯은 같은 영역에 두고, 보유 장비 목록은 그 아래에 배치합니다.
- [탕탕특공대](https://play.google.com/store/apps/details?id=com.dxx.firenow)의 중앙 전투 시야를 참고했습니다. FreeSurvivor는 하단 스킬 슬롯의 별도 줄에 피해 숫자를 표시합니다.
- [궁수의 전설 2](https://play.google.com/store/apps/details?id=com.xq.archeroii)의 강화 선택 구성을 참고했습니다. 카드의 아이콘·이름·분류·효과를 순서대로 보여주고 적용 스킬과 예상 피해를 아래에 표시합니다.
## 2026-11-27 UI 정리 패스

- 장비 관리와 증강 카드의 상단 이동을 제목 옆 작은 버튼으로 분리하지 않고, 동일 폭의 2탭 스트립으로 통일합니다.
- 오버레이로 추가되는 실제 터치 버튼은 기존 배경 그림의 장식 프레임과 겹치지 않도록 얇은 테두리·작은 그림자의 평면형 스타일을 사용합니다.
- 화면의 정보 순서는 `현재 위치/탭 → 핵심 콘텐츠 → 비교·상세 → 하단 주요 행동`으로 고정하고, 같은 기능을 두 곳에 노출하지 않습니다.
