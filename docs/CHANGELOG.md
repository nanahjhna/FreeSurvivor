# 변경 내역

## 2026-11-27

- 승인 시안 15개 화면과 검사 스킬 이펙트를 포함한 Android AAB 2.2(버전 코드 12)를 빌드하고 출시 서명을 확인했습니다.

- 검사의 Q/W/E/R에 전용 검기 궤적, 이중 착지 충격파와 지면 균열, 명중 불꽃을 적용했습니다.

- 사용자 승인 원본 이미지 5장 · 15개 화면을 각각 게임 씬에 연결했습니다. 실제 캐릭터와 전장, 저장 데이터, 버튼 동작을 시안과 함께 표시합니다.

- 승인 UI 시안에서 분리한 버튼·프레임·아이콘 이미지를 공통 스킨으로 적용했습니다.

- 승인된 세로 UI 구성을 실제 게임에 적용했습니다. 마을 목표·던전 이동, 장비 비교, 증강 미리보기, 전투 및 마을 메뉴에 공통 테마를 적용하고 기존 3D 캐릭터를 표시합니다.

## 2026-11-26

- 장비·증강 카드·내 스킬·전투 HUD·마을 메뉴의 세로 화면 가독성과 버튼 배치를 개선했습니다.

- 프로젝트 문서 체계 추가
- 게임 규칙, UI/UX 규격, 데이터 구조, 구현 현황 문서 추가
- 대화 기록과 문서 갱신 규칙 추가
- `AGENTS.md`에 문서 및 대화 기록 규칙 연결
- 세로 고정 및 모바일 안전 영역 기준 반영
- 좁은 화면의 공통 여백과 UI 간격 축소
- 캐릭터 선택·던전 입장·레벨업·장비·전투 HUD의 고정 크기와 전체 스크롤 보정
- 마을 1인칭 카메라와 전투 쿼터뷰 카메라 분리
- 마을 오버숄더 카메라와 방향키/가상 조이스틱 이동 보정
- 여관 구매 경험치를 영구 캐릭터 EXP로 통합하고 캐릭터 총 레벨/레벨업 능력치 흐름 추가
- 캐릭터 정보·성장 화면에 총 레벨과 영구 EXP 진행 바 표시
- 장비 관리·대장간에 신발 장비 타입과 신발 슬롯 추가
- 전투 액티브 스킬 슬롯을 Q/W/E/R 4개로 고정하고 패시브 자동 적용 표시 유지
- 내 스킬 카드 가로 슬라이드와 실제 캐릭터 스킬 애니메이션 미리보기 추가
- 내 스킬 화면을 레퍼런스형 다크 프레임, 확대 미리보기, 페이지 점, 1~4 슬롯 스트립으로 보정
- 실행 화면 전체를 확인하고 화면별 레퍼런스·디자인 전용 수정 범위를 `docs/UI_REFERENCE_REVIEW.md`에 기록
- 가로형 레퍼런스를 최종 기준에서 제외하고 사용자 제공 세로형 레퍼런스 묶음으로 재선정
- 캐릭터 선택 레퍼런스의 가로형 이미지를 제외하고 세로형 목록·중앙 프리뷰 구조로 교체
- 화면군별 레퍼런스를 적용하되 `UiStyle` 공통 토큰을 공유하는 일관성 규칙 추가
- 모든 화면에 하나의 다크 판타지 숯색·청동·앰버 테마를 적용하는 기준 확정
- 전체 UI 테마를 다크 판타지에서 아포칼립스 생존풍으로 변경
- 공통 철판 프레임과 황색 강조 스타일을 주요 Godot UI에 적용
- 생존자 거점 테마로 주요 세로 UI를 재배치하고 나무 제목판·종이 카드·벽돌색 버튼 적용
- 공유 애니메이션 압축과 텍스처 해상도 상한으로 Android AAB 용량 최적화
- Android AAB 반복 빌드 규칙 문서화: 출력 경로, 버전·서명·ABI 확인, 텍스처·애니메이션 보존 및 최적화, 빌드 후 검증 절차
- Android AAB 빌드 전후에 직전 번들보다 버전명과 버전 코드가 모두 증가했는지 확인하도록 규칙 보완
- Android AAB 2.1(버전 코드 11) 빌드 및 출시 서명 검증 완료
- 검사 기본공격을 제거하고 Q 스킬에 한손 곤봉 연속기 애니메이션과 검기를 연결

- 자동 스킬 슬롯별 토글, 광역 최소 대상 수, 발동 직전 재타겟팅, 수동 입력 우선권, 점수 기반 자동 우선순위, 1개 스킬 대기열 추가
- 플레이어 스킬과 타격의 재생 동기화, 약한 피격 중 재생 보호, 연속기 뒤 보행 복귀 보완
- 검사 기본 스킬을 대검 동작으로 재구성하고 검기와 착지의 피해 판정 및 전투 HUD 체력 표시 보완
