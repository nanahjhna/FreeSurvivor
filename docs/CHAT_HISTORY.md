# 대화 기록 및 합의 사항

이 파일은 FreeSurvivor 개발과 관련해 사용자와 합의한 내용을 요약합니다. 채팅 원문 전체가 아니라 구현에 필요한 결정과 보류 사항을 기록합니다.

## 2026-11-26 — UI 개선 범위 및 기록 체계

### 요청 요약

- 기존 Godot 4 프로젝트의 전투·캐릭터·애니메이션·이동·카메라·저장 시스템은 유지합니다.
- 모바일 세로형 RPG 기준으로 타이틀, 캐릭터 선택/생성, 던전 입장, 전투, 결과, 캐릭터 정보, 장비, 인벤토리, 아이템 상세 팝업, 대장간, 영구 성장, 레벨업 스킬 선택, 설정/일시정지 화면을 개선합니다.
- 마을 화면은 기존 구현과 시야를 우선하며 불필요하게 새로 만들지 않습니다.
- 캐릭터 외형은 임의의 새 캐릭터를 만들지 않고 프로젝트에 등록된 실제 캐릭터 데이터를 사용합니다.
- 레퍼런스의 분위기와 정보 배치는 참고하되, 게임에 없는 기능을 있는 것처럼 표시하지 않습니다.
- 변경 후 테스트 검토를 별도로 진행하지 않으며, 확인하지 않은 부분은 문서에서 명확히 표시합니다.

### 문서화 결정

- `AGENTS.md`에 문서·대화 기록 갱신 규칙을 추가했습니다.
- 설계 문서는 `docs/`에 분리합니다.
- 이후 중요한 요청과 합의는 `docs/CHAT_HISTORY.md`에 날짜별로 추가합니다.
- 구현 상태는 `docs/IMPLEMENTATION_STATUS.md`에서 구현/부분 구현/미구현으로 구분합니다.

### 보류 사항

- 실제 대장간, 영구 성장, 던전 데이터 연결 여부는 코드 상태 확인 후 확정합니다.
- Godot 에디터의 포트 충돌 및 중복 `reimport` 오류는 별도 환경 문제로 기록만 하며, 이 문서 생성 작업에서 수정하지 않습니다.

## 2026-11-26 — 세로형 모바일 레이아웃 보정

### 요청 요약

- 세로 화면 모바일 최적화 검토 항목을 실제 코드에 반영합니다.
- 화면 UI의 불필요한 여백과 전체 화면 스크롤을 줄이고, 콘텐츠가 화면 안에 맞도록 합니다.

### 반영 내용

- `project.godot`: Android 화면 방향을 세로 고정으로 설정했습니다.
- `scripts/ui_style.gd`: 좁은 세로 화면의 공통 여백·간격을 축소하고, 스크롤 컨테이너의 가로 넘침을 막았습니다.
- `scenes/ui/character_select.gd`: 화면 전체 스크롤을 제거하고 실제 화면 크기에 맞춰 캐릭터 미리보기 크기를 계산합니다.
- `scenes/ui/battle_prep_ui.gd`: 던전 입장 본문을 고정 레이아웃으로 바꾸고 미리보기·글자 크기를 화면 높이에 맞췄습니다.
- `scenes/ui/level_up_panel.gd`: 카드 크기와 열 수를 화면 폭·높이에 맞춰 계산합니다.
- `scenes/ui/inventory_ui.gd`: 장비 슬롯과 캐릭터 초상화 크기를 좁은 화면에서 축소합니다.
- `scenes/ui/hud.gd`: 전투 스킬 바의 슬롯 폭·높이·간격을 화면 폭에 맞춰 조정합니다.
- `scenes/ui/game_over_screen.gd`: 결과 화면의 문장 장식 높이를 화면 높이에 맞춥니다.

### 검토 제한

- 사용자의 요청에 따라 Godot 실행 테스트와 기기별 실제 화면 검토는 이 작업에서 수행하지 않았습니다.

## 2026-11-26 — 캐릭터 레벨·능력치 레벨·여관 경험치 흐름 통합

### 사용자 합의 흐름

- `캐릭터 Lv.`은 전투 레벨과 별개의 영구 총 레벨로 표시합니다.
- 여관에서 골드를 사용해 선택 캐릭터의 영구 경험치를 구매합니다.
- 구매 경험치는 캐릭터 EXP 바에 누적되고, 다음 레벨 필요량 이상이면 초과분을 남긴 채 캐릭터 레벨이 오릅니다.
- 캐릭터 레벨업 때만 직업별 성장 능력치 묶음이 적용됩니다. 힘·민첩·체력 등 개별 능력치 레벨은 상세 정보로 유지합니다.
- 전투 중 레벨/경험치와 영구 캐릭터 레벨/경험치는 서로 섞지 않습니다.

### 반영 파일

- `scripts/game_data.gd`: 영구 캐릭터 EXP·다음 레벨 필요량·레벨업 성장 적용·기존 저장 마이그레이션
- `scenes/ui/character_management_ui.gd`: 캐릭터 총 레벨과 EXP 바, 구매 결과 표시
- `scenes/ui/village_hud.gd`: 마을 상단에 실제 캐릭터 이름·총 레벨 표시
- `scenes/ui/inventory_ui.gd`: 장비 관리 화면에 캐릭터 총 레벨 표시

## 2026-11-26 — 전체 화면 디자인 검토 및 레퍼런스 매핑

### 사용자 요청

- 각 화면을 실제 실행 화면으로 확인하고 화면별 레퍼런스를 찾아 UI 디자인을 수정합니다.
- 기능·데이터·저장·입력 로직은 변경하지 않고 시각 디자인만 다룹니다.
- 기존 캐릭터와 프로젝트 에셋을 사용하며 레퍼런스 캐릭터를 새로 만들거나 복제하지 않습니다.

### 확인 및 결정

- 타이틀, 캐릭터 선택, 마을, 캐릭터 정보, 장비/가방, 아이템 상세, 내 스킬, 자동 이동, 던전 선택, 전투 시작 카드 화면을 Godot 실행 화면에서 확인했습니다.
- 레벨업 선택, 일시정지/설정, 전투 결과는 기존 씬·코드와 사용자 제공 레퍼런스를 기준으로 디자인 방향을 문서화했습니다.
- 화면별 참고 방향과 구현 순서는 `docs/UI_REFERENCE_REVIEW.md`로 분리했습니다.

### 보류

- 화면별 공통 스타일 토큰과 수정 우선순위를 확정하기 전에는 대규모 UI 코드 수정에 들어가지 않습니다.
- 이 작업에서 아직 디자인 코드 변경은 적용하지 않았습니다.
