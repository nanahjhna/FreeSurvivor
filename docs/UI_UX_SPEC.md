# UI/UX 화면 규격

## 공통 규칙

- 세로 화면과 터치 조작을 우선합니다.
- 기준 해상도는 1080×1920이며 노치와 안전 영역을 고려합니다.
- 다크 판타지 미니멀 RPG 분위기를 사용하되, 기존 캐릭터와 월드의 시야를 가리지 않습니다.
- 두꺼운 검은 패널과 중복 정보는 피합니다.
- 화면 전체를 세로로 스크롤하는 구조는 사용하지 않습니다. 스크롤은 인벤토리 목록·도감·키 목록처럼 데이터가 늘어나는 영역에만 제한적으로 사용합니다.
- 고정 최소 높이와 큰 여백을 피하고, 화면 높이와 안전 영역을 기준으로 콘텐츠 크기를 계산합니다.
- 새 화면은 기존 씬과 데이터에 연결하고, 미구현 기능을 작동하는 것처럼 보여주지 않습니다.

## 화면 흐름

```text
타이틀 → 캐릭터 선택/생성 → 마을
마을 → 캐릭터 정보 / 장비 / 인벤토리 / 대장간 / 영구 성장 / 설정
마을 → 던전 입장 → 전투 → 레벨업 선택 또는 일시정지 → 전투 결과
전투 결과 → 다시 도전 또는 마을 복귀
```

## 화면별 핵심 정보

| 화면 | 핵심 요소 |
| --- | --- |
| 타이틀 | 게임 시작, 설정, 기존 저장 진입 |
| 캐릭터 선택/생성 | 실제 등록 캐릭터 모델, 직업, 능력치, 장비, 선택/생성 |
| 마을 | 캐릭터 정보, 재화, 시설 접근, 던전 바로가기 |
| 던전 입장 | 던전 목록, 난이도, 목표 시간, 몬스터, 보상, 입장 |
| 전투 | 경험치, 레벨, 생존 시간, 골드, 처치 수, 보스 HP, 조이스틱, 스킬 |
| 레벨업 팝업 | 실제 선택 가능한 스킬 카드와 설명 |
| 전투 결과 | 생존 결과, 기록, 피해량, 보상, 재도전/복귀 |
| 캐릭터 정보 | `캐릭터 Lv.`와 영구 EXP 바, 실제 능력치와 장착 장비 |
| 장비/인벤토리 | 보유 아이템, 장착 상태, 등급, 상세 팝업 |
| 대장간 | 기존 장비 강화 데이터와 비용 |
| 영구 성장 | 여관 구매 EXP, 캐릭터 총 레벨, 다음 레벨 EXP, 직업별 능력치 성장 |
| 설정/일시정지 | 사운드, 진동, 그래픽, 조작, 재개/종료 |

## 입력

- PC: 기존 키보드 입력(Q/W/E/R 포함)을 유지합니다.
- 내 스킬 화면은 Q/W/E/R 4개 액티브 슬롯과 캐릭터 패시브 1개를 표시합니다.
- 내 스킬 화면의 액티브 스킬 카드는 한 장씩 가로로 밀어 넘기며, 선택한 실제 캐릭터 모델이 해당 스킬 애니메이션을 반복 재생합니다.
- 마을 PC 이동: 방향키만 사용하며 마우스 드래그로 카메라를 회전하지 않습니다.
- 모바일: 마을과 전투에서 가상 이동 조이스틱과 터치 가능한 스킬·메뉴 버튼을 제공합니다.
- 뒤로가기와 닫기는 현재 화면을 안전하게 종료하며 전투 상태를 임의로 초기화하지 않습니다.
