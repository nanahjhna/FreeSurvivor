# UI/UX 화면 규격

## 공통 규칙

- 세로 화면과 터치 조작을 우선합니다.
- 기준 해상도는 1080×1920이며 노치와 안전 영역을 고려합니다.
- 아포칼립스 생존 RPG 분위기를 사용하되, 기존 캐릭터와 월드의 시야를 가리지 않습니다.
- 공통 `UiStyle`의 어두운 금속색 패널, 얇은 청동색 테두리, 아이보리 글자와 단순한 아이콘을 사용합니다. 핵심 행동 버튼은 녹슨 주황색, 선택 테두리는 밝은 청동색으로 표시합니다.
- 승인 시안에서 분리한 투명 PNG의 버튼·패널·선택 테두리를 9분할 이미지로 표시합니다. 공통 메뉴와 장비의 아이콘은 별도 PNG 영역을 사용합니다. 이름, 수치와 터치 영역은 Godot 컨트롤에서 관리합니다.
- UI 표면과 모서리에는 풀·덩굴·잎사귀 장식을 넣지 않습니다. 타이틀과 초원 외곽 선택 화면은 승인 시안의 배경을 사용합니다. 실제 전투와 일시정지 뒤에는 진행 중인 전장 씬을 표시합니다.
- 두꺼운 검은 패널과 중복 정보는 피합니다.
- 화면 전체를 세로로 스크롤하는 구조는 사용하지 않습니다. 스크롤은 인벤토리 목록·도감·키 목록처럼 데이터가 늘어나는 영역에만 제한적으로 사용합니다.
- 고정 최소 높이와 큰 여백을 피하고, 화면 높이와 안전 영역을 기준으로 콘텐츠 크기를 계산합니다.
- 새 화면은 기존 씬과 데이터에 연결하고, 미구현 기능을 작동하는 것처럼 보여주지 않습니다. 캐릭터 이미지를 표시하는 자리는 등록된 `CharacterData.model_scene`에서 기존 모델을 불러와 그립니다.

## 화면 흐름

```text
타이틀 → 캐릭터 선택/생성 → 마을
마을 → 캐릭터 정보 / 장비 관리 / 대장간 / 영구 성장 / 설정
마을 → 던전 입장 → 전투 → 레벨업 선택 또는 일시정지 → 전투 결과
전투 결과 → 다시 도전 또는 마을 복귀
```

## 화면별 핵심 정보

| 화면 | 핵심 요소 |
| --- | --- |
| 타이틀 | 마을 장면이 화면을 채우고, 중앙에 타이틀과 버튼 묶음을 배치하며 시작·설정·종료 버튼은 같은 폭으로 세로 배치 |
| 캐릭터 선택/생성 | 왼쪽 정렬 제목, 머리까지 보이는 실제 3D 모델 무대, 이름 옆 캐릭터 레벨, 숫자 능력치와 설명 버튼, 가로 캐릭터 슬롯, 생성·삭제 버튼 |
| 마을 | 캐릭터 이름·레벨, 눌러서 여는 지도, 실제 진행도 기준 ‘다음 목표’와 ‘던전으로 이동’. 네 메뉴와 자동 이동 버튼 모서리 알림 |
| 던전 입장 | 던전 목록, 스테이지 미리보기, 목표·등장 적·보상·기록 안내문, 하단 입장 버튼 |
| 전투 | 경험치, 레벨, 생존 시간, 골드, 처치 수, 보스 HP, 조이스틱, 현재/최대 체력. 같은 폭의 Q/W/E/R 슬롯과 슬롯 하단의 예상 피해 |
| 레벨업 팝업 | 가로형 카드를 세로로 배치하고 분류 아이콘, 이름, 효과, 적용 전후 수치를 표시. 기본 세 선택지는 한 화면에 두며 넘치는 카드 목록만 스크롤 |
| 전투 결과 | 어두운 결과 기록판에 생존 결과와 시간·핵심 수치, 보상, 하단의 재도전·복귀 버튼 |
| 캐릭터 정보 | 캐릭터 이름과 총 레벨, 영구 EXP 바, 실제 능력치와 직업 효과 |
| 장비 관리 | `장비 관리 / 증강 카드` 탭. 실제 3D 전신과 네 슬롯, 보유 장비 목록, 전후 비교, 장착 버튼을 한 화면에 표시. 증강 카드 탭은 전투 도감과 카드 던전 보유 카드, 지속되는 상세 화면을 제공 |
| 대장간 | 대장간 제목으로 장비 관리 화면을 재사용. 추천 장착 버튼은 한 곳에 표시 |
| 영구 성장 | 캐릭터 총 레벨, 현재 EXP, 여관 구매 시 증가량과 다음 레벨까지의 EXP, 비용 |
| 설정/일시정지 | 지원되는 음량·조작·카메라 설정과 재개·재시작·마을 복귀 |
| 마을 지도·자동 이동 | 실제 지형 기준 미니맵과 시설 선택, 선택한 장소로 이동하는 버튼 |

## 입력

- PC: 기존 키보드 입력(Q/W/E/R 포함)을 유지합니다.
- 내 스킬 화면은 Q/W/E/R 4개 액티브 슬롯과 캐릭터 패시브 1개를 표시합니다.
- 내 스킬 화면의 좌우 버튼이나 미리보기 가로 스와이프로 액티브 스킬을 넘기면, 실제 캐릭터 모델이 해당 스킬 애니메이션을 반복 재생합니다.
- 액티브 스킬 카드에 아이콘과 스킬명을 표시하고, 재사용·계수·사거리는 한 줄에 배치합니다. 피해 공식은 현재 캐릭터 능력치·장비·전투 보너스를 반영해 `공격력 × 계수 = 결과값`으로 표시합니다.
- DEX의 연결 능력치는 `시전 속도`로 표시합니다. 시전 속도는 스킬 애니메이션·타격 시점을 빠르게 하며, 스킬 쿨다운을 줄이지 않는다는 설명을 함께 제공합니다.
- 마을 PC 이동: 방향키만 사용하며 마우스 드래그로 카메라를 회전하지 않습니다.
- 모바일: 마을과 전투에서 가상 이동 조이스틱과 터치 가능한 스킬·메뉴 버튼을 제공합니다.
- 전투 스킬은 슬롯을 짧게 눌러 시전하고 길게 눌러 해당 슬롯의 자동 시전을 전환합니다. 이동으로 취소하거나 슬롯 밖에서 떼면 시전하지 않습니다. 설명창과 알림이 떠 있어도 아래 버튼을 누를 수 있습니다.
- 캐릭터 생성 버튼은 이름과 직업이 유효할 때 활성화되며, 입력이 필요한 경우 버튼 아래에 이유를 표시합니다.
- 선택 가능한 증강 카드를 모두 소진하면 선택창을 닫고 전투를 재개합니다.
- 뒤로가기와 닫기는 현재 화면을 안전하게 종료하며 전투 상태를 임의로 초기화하지 않습니다.

## 디자인 검토 원칙

- 외부 상용 게임 레퍼런스는 정보 위계와 조작 배치 검토에 사용합니다. FreeSurvivor용으로 승인된 5장의 자체 시안은 각각 세 화면으로 분리해 해당 씬의 실제 배경, 프레임, 버튼 그래픽으로 사용합니다.
- 디자인 검토와 구현은 기능 변경과 분리합니다. 저장·데이터·전투·입력 로직을 바꾸지 않고 기존 컨트롤과 신호를 유지합니다.
- 현재 실행 화면과 레퍼런스 매핑은 `docs/UI_REFERENCE_REVIEW.md`에서 관리합니다.

## 2026-11-27 승인 원본 15개 화면

- 첫 번째 시안은 타이틀, 캐릭터 선택, 캐릭터 생성에 연결합니다. 두 번째는 캐릭터 정보, 성장, 내 스킬에 연결합니다. 세 번째는 퀘스트, 증강 도감, 증강 카드 상세에 연결합니다. 네 번째는 일시정지, 환경 설정, 장비 관리와 대장간에 연결합니다. 다섯 번째는 던전 선택, 전투 HUD, 전투 결과에 연결합니다.
- 원본 화면은 552×940의 논리 크기로 배치하고 안전 영역 안에 비율을 유지해 표시합니다. 원본의 캐릭터 영역에는 실제 3D 프리뷰를 합성합니다. 캐릭터에 가렸던 배경은 복원한 대장간 이미지로 보완합니다.
- 표본 이름·레벨·능력치·재화·보상·피해량은 실행 상태의 값으로 표시합니다. 증강 상세는 적용된 Q/W/E/R 슬롯의 스킬명과 피해 전후 수치를 표시합니다. 퀘스트와 장비 및 도감 목록은 보유 데이터와 진행도에 따라 늘어납니다.
- 환경 설정에서는 공통 BGM/SFX 음량을 제공하며, 마을·던전 배경음악 트랙은 현재 미제공입니다. 진동과 그래픽 품질 선택은 미지원으로 표시합니다. 조작 설정은 기존의 카메라, 키 설정 및 HUD 편집을 엽니다.
## 2026-11-27 UI 배치 정리 원칙

- 상단 내비게이션은 제목·닫기와 탭을 섞지 않고, 화면 목적이 여러 개인 경우 동일 폭의 탭 2개를 한 줄에 배치합니다.
- 화면 위에 놓이는 터치 오버레이 버튼은 얇은 테두리와 작은 그림자의 평면형 버튼을 사용하고, 같은 행동을 반복해서 보여주는 장식 버튼은 만들지 않습니다.
- 화면의 정보 순서는 `현재 위치/탭 → 핵심 콘텐츠 → 비교·상세 → 하단 주요 행동`으로 유지합니다.
