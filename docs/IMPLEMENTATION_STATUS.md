# 구현 현황

이 문서는 현재 코드에 실제로 연결된 기능과 아직 연결되지 않은 기능을 구분하기 위한 목록입니다.

## 기준

- **구현**: 기존 씬·스크립트·데이터로 동작하는 기능
- **부분 구현**: 화면 또는 데이터 일부만 연결된 기능
- **미구현**: 설계만 있고 실제 동작 경로가 없는 기능

## 화면 및 시스템

| 항목 | 상태 | 비고 |
| --- | --- | --- |
| 타이틀 화면 | 부분 구현 | 기존 타이틀 씬과 저장 진입 경로 기준 |
| 캐릭터 선택 | 구현/확장 대상 | `CharacterRegistry`와 `CharacterData` 우선 |
| 캐릭터 생성 | 부분 구현 | 실제 등록 모델과 데이터 연결 필요 |
| 3D 마을 | 구현 | 기존 마을 씬·이동·시설을 보존 |
| 던전 입장 | 부분 구현 | 실제 던전 데이터 연결 여부 확인 필요 |
| 전투 HUD | 부분 구현 | 기존 전투 로직과 입력을 유지 |
| 레벨업 스킬 선택 | 부분 구현 | 기존 스킬 데이터와 선택 처리 연결 필요 |
| 전투 결과 | 부분 구현 | 보상 중복 방지와 저장 연동 필요 |
| 캐릭터 정보/장비/인벤토리 | 부분 구현 | 실제 장착·아이템 데이터 연결 필요 |
| 대장간 | 미구현 또는 별도 확인 | 구현 전 기존 강화 시스템 확인 |
| 영구 능력치 강화 | 미구현 또는 별도 확인 | 실제 재화·저장 연동 필요 |
| 설정/일시정지 | 부분 구현 | 기존 설정과 전투 일시정지 경로 재사용 |

## 2026-11-26 모바일 세로 레이아웃 보정

- 세로 고정 방향과 안전 영역 기준을 프로젝트 설정에 반영했습니다.
- 공통 다이얼로그의 좁은 화면 여백과 컨테이너 간격을 축소했습니다.
- 캐릭터 선택 화면의 전체 페이지 스크롤을 제거하고, 미리보기 크기를 화면 높이에 맞췄습니다.
- 던전 입장 화면은 본문 전체 스크롤 대신 화면에 맞는 미리보기 높이를 사용합니다.
- 레벨업 카드, 전투 스킬 바, 장비 슬롯을 화면 폭에 따라 축소합니다.
- 데이터가 늘어나는 목록의 스크롤은 유지하며, 임의로 기능을 제거하지 않았습니다.

## 카메라

- 마을 오버숄더 3인칭: 구현 (`scenes/stages/village_lobby.gd`)
- 마을 캐릭터 팔/무기 노출 거리: 구현 (`scenes/player/player_camera.gd`, `scenes/stages/village_lobby.gd`)
- 전투 쿼터뷰: 기존 구현 유지 (`scenes/stages/stage_grassland.gd`)
- 마을 방향키·모바일 가상 조이스틱 입력: 구현 (`scenes/player/player.gd`, `scenes/ui/virtual_dpad.gd`, `scenes/ui/village_hud.gd`)
- 설정 화면에서 마을 카메라 강제 변경 방지: 구현 (`scenes/ui/settings_ui.gd`)

상태는 코드가 변경될 때 함께 갱신합니다. 확인하지 못한 기능을 `구현`으로 승격하지 않습니다.
