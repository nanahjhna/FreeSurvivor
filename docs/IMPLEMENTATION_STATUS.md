# 구현 현황

이 문서는 현재 코드에 실제로 연결된 기능과 아직 연결되지 않은 기능을 구분하기 위한 목록입니다.

## 기준

- **구현**: 기존 씬·스크립트·데이터로 동작하는 기능
- **부분 구현**: 화면 또는 데이터 일부만 연결된 기능
- **미구현**: 설계만 있고 실제 동작 경로가 없는 기능

## 화면 및 시스템

| 항목 | 상태 | 비고 |
| --- | --- | --- |
| 타이틀 화면 | 부분 구현 | 기존 타이틀 씬과 저장 진입 경로 기준 |

| 설정/일시정지 | 부분 구현 | 기존 설정과 전투 일시정지 경로 재사용 |

## 2026-11-28 캐릭터 선택 능력치 느낌표 배경 정리

캐릭터 선택 승인 화면에서 원본 이미지의 능력치 장식 아이콘이 새 느낌표 정보 버튼 뒤에 비치는 문제를 수정했습니다. 느낌표 버튼 영역을 패널색으로 먼저 덮은 뒤 기존 버튼을 배치해 중복 오브젝트만 숨겼으며, 능력치 상세 팝업과 선택 흐름은 유지합니다. 실제 Godot 화면 캡처와 Android 기기 검증은 아직 진행하지 못했습니다.


## 2026-11-28 캐릭터 선택 화면 미표시 오류 수정

느낌표 뒤 장식 제거 코드를 반복문 본문보다 깊게 삽입해 발생한 GDScript 들여쓰기 오류를 확인하고 정상 들여쓰기로 수정했습니다. 이 오류로 캐릭터 선택 화면 초기화가 중단될 수 있었습니다. `git diff --check`는 통과했으며 Godot 실행 파일은 현재 환경에서 찾지 못해 실제 화면 재실행은 확인하지 못했습니다.


## 2026-11-28 상세 전투 기록 독립 팝업

전투 결과 화면의 `상세 전투 기록` 버튼이 기존 레거시 결과 레이아웃 전체를 다시 표시하던 동작을 제거했습니다. 이제 버튼을 누르면 결과 요약 위에 상세 전투 기록만 담은 별도 팝업이 표시되며, 피해 출처별 수치·비율과 총 피해량, 닫기 버튼을 제공합니다. 기존 결과 화면의 오래된 기록 영역은 팝업을 닫을 때도 다시 표시하지 않습니다. `git diff --check`는 통과했지만 Godot 실행 파일이 없어 실제 화면 검증은 진행하지 못했습니다.


## 2026-11-28 증강 카드 목록 행 높이 통일

증강 카드 도감 목록을 렌더링한 뒤 각 카드 행의 실제 최소 높이를 측정하고, 가장 긴 제목·분류·설명 조합이 필요한 높이를 전체 카드 행에 공통 적용하도록 변경했습니다. 카드별 텍스트 길이에 따라 행이 들쭉날쭉해지는 현상을 없애고 기존 목록 스크롤과 상세 진입은 유지합니다. Godot 실행 파일이 없어 실제 화면에서의 폰트 측정 결과는 아직 확인하지 못했습니다.


## 2026-11-28 증강 카드 행 높이 대상 정정

앞서 도감 목록 행으로 해석했던 변경은 유지하지 않고 원래 동작으로 되돌렸습니다. 실제 요청 대상은 시작·레벨업 카드 선택 화면의 카드 박스이며, `level_up_panel.gd`에서 현재 표시되는 카드들의 실제 최소 높이를 비교해 가장 긴 카드 높이를 전체 카드에 공통 적용하도록 반영했습니다. 화면 폭이 바뀌어 텍스트 줄바꿈이 달라지면 높이를 다시 계산합니다.
