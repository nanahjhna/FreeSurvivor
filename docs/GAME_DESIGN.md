# 게임 규칙 및 설계

## 장르와 핵심 루프

FreeSurvivor는 3D 액션 RPG와 뱀서라이크 로그라이트를 결합한 1인용 게임입니다.

1. 타이틀 화면에서 게임을 시작합니다.
2. 캐릭터를 선택하거나 생성합니다.
3. 마을에서 캐릭터·장비·인벤토리·성장 메뉴를 확인합니다.
4. 던전을 선택하고 전투에 입장합니다.
5. 이동과 액티브 스킬로 생존하며 경험치와 보상을 획득합니다. 기본공격은 사용하지 않습니다.
6. 레벨업 시 제공된 스킬 중 하나를 선택합니다.
7. 전투 종료 후 결과와 보상을 확인하고 재도전하거나 마을로 돌아갑니다.

## 보존해야 하는 기존 시스템

- 플레이어 이동과 카메라
- 전투, 몬스터, 스킬, 애니메이션
- 캐릭터별 `CharacterData`
- 장비·스킬·캐릭터 저장 데이터
- 기존 마을과 시설 상호작용

## 카메라 규칙

- 마을(`Location.LOBBY`)에서는 캐릭터 뒤쪽의 가까운 오버숄더 3인칭 카메라를 사용합니다.
- 마을 카메라는 실제 등록 캐릭터와 장착 무기가 화면 중앙 하단에 보이는 거리로 배치합니다.
- 전투(`Location.BATTLE`)에서는 기존 쿼터뷰 전투 카메라를 유지합니다.
- PC 마을 이동은 방향키만 사용하고, 모바일 마을 이동은 가상 조이스틱을 사용합니다.
- 마을에서는 카메라가 뒤로 재정렬되는 동안 방향키·조이스틱 이동을 멈추지 않습니다.
- 마을에서 카메라 설정을 조작해도 전투 카메라 설정을 강제로 덮어쓰지 않습니다.
- 씬 전환 시 각 씬이 카메라 모드를 명시적으로 설정하여 이전 씬의 카메라 상태가 남지 않게 합니다.

## 성장 규칙

- 전투 중 경험치와 레벨은 해당 전투에만 적용되는 `전투 Lv.` 상태입니다. 전투 종료 후 초기화되며 영구 캐릭터 레벨과 섞지 않습니다.
- 레벨업 선택지는 기존 스킬 데이터베이스와 캐릭터 스킬 설정을 사용합니다.
- 전투 스킬 슬롯은 Q/W/E/R 4개로 고정하고, 패시브 스킬은 캐릭터당 하나를 자동 적용합니다. 기존 저장의 추가 슬롯 값은 전투 슬롯으로 사용하지 않습니다.
- 기본공격 자동 시전과 수동 기본공격 입력은 사용하지 않습니다. 자동 전투도 준비된 액티브 스킬만 시전합니다.
- 검사(`char01`)의 Q는 `Great_Sword_Attack` 대검 베기, W는 `Great_Sword_Slash` 대검 횡베기, E는 `Great_Sword_Jump_Attack` 대검 도약 참격입니다. Q와 W는 전방 검기로, E는 착지 지점 주변 판정으로 피해를 줍니다.
- R `검기 베기`는 `Sword_Regular_A_Rec` → `Sword_Regular_B_Rec` → `Sword_Regular_C_RM`을 순서대로 재생하고 각 타격 시점에 검기를 발사합니다. 연속 스킬은 `SkillData`의 `animation_sequence`와 `effect_scene`를 함께 사용합니다.
- 자동 전투는 슬롯별 토글, 광역 대상 수(`auto_min_targets`), 발동 직전 재타겟팅, 수동 입력 우선권, 점수 기반 후보 선택, 1개 스킬 대기열을 사용합니다. MP·스태미나·분노·탄약·버프 지속시간·시야 판정은 현재 시스템에 없으므로 자동 판단에서 제외합니다.
- 전투 중인 플레이어는 스킬 동작이 끝날 때까지 가벼운 피격으로 시전이 끊기지 않습니다. 사망하면 아직 발생하지 않은 타격을 취소합니다.
- 스킬 타격 시점은 동작의 누적 재생 위치로 결정합니다. `시전 속도` 보너스는 애니메이션과 타격을 함께 앞당기며, 재사용 대기시간은 별도의 스킬 쿨다운 규칙으로 관리합니다.
- 스킬 입력 대기열은 수동 입력을 우선하며, 앞 스킬이 끝나면 자동 사용 조건과 적의 위치를 다시 평가합니다.
- 방향키와 조이스틱 이동 중에도 자동 시전 조건을 평가합니다. 수동 스킬 시전과 유효한 예약에는 1.25초간 우선권을 부여합니다.
- 여관/캐릭터 성장 화면에서 골드로 영구 캐릭터 경험치를 구매합니다.
- 구매한 경험치는 선택 캐릭터의 `캐릭터 EXP` 바에 누적됩니다. 필요 EXP를 넘으면 초과분을 유지한 채 `캐릭터 Lv.`이 1 오르고, 해당 직업의 성장 능력치 묶음이 한 번 적용됩니다.
- 캐릭터 정보·장비·마을 HUD에는 영구 `캐릭터 Lv.`을 표시하고, 힘·민첩·체력 등 개별 능력치는 `STR 5`처럼 실제 숫자로 표시합니다. 직업 효과는 별도 열에 계산 결과로 표시합니다.
- 기존 저장의 `growth_level`, 능력치, 레벨 값은 마이그레이션 후 새 캐릭터 경험치 필드와 함께 보존합니다.
- 장비 능력치는 장비 데이터와 장착 상태에 따라 계산합니다.
- 같은 보상이나 재화를 전투 결과에서 중복 지급하지 않습니다.

## 확장 규칙

- 캐릭터와 던전 목록은 하드코딩하지 않고 레지스트리 또는 데이터 리소스에서 생성합니다.
- 잠금 콘텐츠는 실제 해금 조건을 표시합니다.
- 존재하지 않는 캐릭터, 던전, 스킬, 보상을 임의로 표시하지 않습니다.
